## Question

There are at least six domain-specific languages used in the little system I cobbled together to write and publish this book. What are they?

[Repo link](https://github.com/munificent/craftinginterpreters)  

## My Explanation

**domain-specific languages**: Simply referred to as DSL. A language that focuses on a single problem or area (domain). Basicly, not creating a language that can do everything, but instead creating a language that solves a specific problem. For instance,
- SQL is created to implement database operations
- Regular Expressions are created to analyze patterns in text
- CSS is created to style web pages

**general purpose languages:** A language that can be used for many different domains. For instance, python, java, c.
